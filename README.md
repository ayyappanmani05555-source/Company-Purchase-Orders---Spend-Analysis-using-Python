# Company-Purchase-Orders---Spend-Analysis-using-Python
## 1. Project Objective
The objective of this project is to analyze purchase data to improve procurement efficiency, monitor supplier performance, optimize purchasing costs, and support data-driven business decisions. The project integrates Microsoft Excel for data preparation, Python for data cleaning and analysis, and Power BI for interactive dashboard creation and business intelligence reporting.

## 2. KPI Questions
## Purchase Performance

2. How many Purchase Orders were created?

4. What is the Total Quantity Purchased?

1. Who is the Top Supplier by Purchase Value?
2. Which supplier delivered the highest quantity?
3. Which suppliers have the highest purchase frequency?
4. Which suppliers contribute the most to total spending?
## Product Analysis
1. Which products are purchased the most?
2. Which products generate the highest purchasing cost?
3. Which categories require frequent replenishment?
4. What are the least purchased products?
## Time-Based Analysis
1. What are the monthly purchase trends?
2. Which quarter has the highest procurement cost?
3. How has purchasing changed year over year?
3. Are there any seasonal purchasing patterns?
## Regional Analysis (if applicable)
1. Which branch or warehouse has the highest purchase volume?
2. Which location spends the most on procurement?
## Financial KPIs

3. Purchase Growth (%)
4. Cost Distribution by Category
5. Supplier Contribution (%)

## 3. Project Process
## Data Collection
1. Collected purchase transaction data from business records.
2. Imported the dataset into Microsoft Excel.
## Data Cleaning using Python
Using Pandas and NumPy, the following preprocessing tasks were performed:
1. Removed duplicate records.
2. Handled missing values.
3. Corrected inconsistent data formats.
4. Standardized supplier and product names.
5. Converted date columns into proper datetime format.
6. Validated numeric fields.
7. Created calculated fields for reporting.
## Exploratory Data Analysis (EDA)
Performed analysis using Python:
1. Supplier-wise purchase analysis.
2. Product-wise cost analysis.
3. Monthly purchase trends.
4. Category-wise spending.
5. Purchase frequency analysis.
6. Cost distribution.
## Data Preparation in Excel
Used Excel features such as:
1. Pivot Tables
2. Pivot Charts
3. Conditional Formatting
4. Lookup Functions (XLOOKUP/VLOOKUP)
5. IF, SUMIFS, COUNTIFS
6. Data Validation
## Power BI Dashboard Development
Imported the cleaned Excel dataset into Power BI and created:
1. Data Model
2. Relationships
3. DAX Measures
4. Calculated Columns
5. Interactive Dashboard
