# Company-Purchase-Orders---Spend-Analysis-using-Python
## 1. Project Objective
The objective of this project is to analyze purchase data to improve procurement efficiency, monitor supplier performance, optimize purchasing costs, and support data-driven business decisions. The project integrates Microsoft Excel for data preparation, Python for data cleaning and analysis, and Power BI for interactive dashboard creation and business intelligence reporting.

6. Validated numeric fields.
7. Created calculated fields for reporting.

## 5. Project Insights

3. Monthly analysis revealed periods of increased purchasing activity.
